# Data Science Internship Projects

A portfolio of end-to-end data science projects covering data cleaning, exploratory data analysis, supervised machine learning, and retail business analytics.

**Repository owner:** [dar2006sh8an13](https://github.com/dar2006sh8an13)  
**Primary language:** Python

## Projects

| # | Project | Description | Project link |
|---|---|---|---|
| 1 | Data Cleaning & Visualization | Data preparation, cleaning, visualization, and an interactive dashboard. Private employee data is intentionally not published. | [View files](src/) |
| 2 | Supervised Learning & Model Evaluation | Logistic Regression, Decision Tree, and Random Forest classification with evaluation metrics and tests. | [View Project 2](supervised-learning/README.md) |
| 3 | Exploratory Data Analysis (EDA) | Statistical exploration of the diabetes dataset, feature distributions, correlation analysis, and visualizations. | [View Project 3](eda/README.md) |
| 4 | Retail Sales Analytics | End-to-end analysis of the Sample Superstore retail dataset, with business KPIs, profitability analysis, charts, and recommendations. | [View Project 4](real-world-retail/README.md) |

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/dar2006sh8an13/data-science-internship.git
   cd data-science-internship
   ```
2. Create and activate a virtual environment.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Open an individual project folder and follow its README for project-specific instructions.

## Notes

- Datasets are public or built into the relevant libraries unless otherwise documented.
- Project 1's private employee workbook is not included.
- The Sample Superstore dataset is fictional and is used for educational business analysis.
- Do not commit confidential data, personal information, API keys, or passwords.
